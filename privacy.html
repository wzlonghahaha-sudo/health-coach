Health Coach Privacy Policy

Last updated: October 11, 2026

Who uses this app

Health Coach is a personal app used solely by its owner, wzlonghahaha@gmail.com. It is not available to other users.

Data accessed

Through Google OAuth, the app requests read-only access to the owner's own Fitbit / Google Health data (such as activity, sleep, heart rate and similar health metrics). It does not modify or delete any data.

How data is used

The data is used only to generate personal health summaries for the owner. It is not used for advertising, profiling, or any other purpose.

Storage and sharing

Data is stored privately and securely under the owner's control. It is never shared with, transferred to, or sold to any third party.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Stored data can be deleted on request.
